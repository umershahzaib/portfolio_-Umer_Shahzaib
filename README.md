# Umer Shahzaib - Developer Portfolio

A premium, cinematic developer portfolio showcasing my work at the intersection of code and AI.

## 🚀 Features

- **Interactive 3D Avatar**: Mouse-tracking parallax effects with video scrubbing capability
- **Cinematic Design**: Dark theme with electric blue accents and smooth animations
- **Custom Cursor**: Dynamic cursor effects for an immersive experience
- **Responsive Layout**: Optimized for desktop, tablet, and mobile devices
- **Smooth Animations**: Built with Framer Motion and GSAP
- **Project Showcase**: Featured projects with live demos and GitHub links
- **Contact Form**: Easy way to get in touch

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion, GSAP
- **Icons**: Lucide React
- **Language**: TypeScript

## 📦 Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

## 🎨 Customization

### Adding Your Avatar

1. Place your 3D avatar image at `public/assets/avatar.png`
2. (Optional) Add video at `public/assets/avatar.mp4` for interactive scrubbing

### Updating Content

- Edit personal information in `components/Hero.tsx`
- Update projects in `components/Projects.tsx`
- Modify skills in `components/Skills.tsx`
- Change contact details in `components/Contact.tsx`

## 📱 Sections

1. **Hero** - Animated introduction with interactive avatar
2. **About** - Overview of passions and expertise
3. **Projects** - Featured work with live demos
4. **Skills** - Technical proficiencies with visual bars
5. **Contact** - Get in touch form and social links

## 🌐 Deployment

This portfolio can be deployed on:

- **Vercel** (Recommended for Next.js)
- **Netlify**
- **GitHub Pages** (requires static export)

```bash
# Deploy to Vercel
vercel

# Or build static export
npm run build
```
